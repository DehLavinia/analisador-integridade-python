# Analisador de Integridade de Arquivos com Python

## Sobre o projeto

Projeto desenvolvido em Python com o objetivo de verificar a integridade de arquivos por meio do algoritmo de hash SHA-256.

A ferramenta permite calcular hashes e identificar alterações no conteúdo de arquivos, contribuindo para o estudo de conceitos de Segurança da Informação.

## Funcionalidades

- Verificação da integridade de arquivos.
- Cálculo de hash SHA-256.
- Armazenamento individual dos hashes originais.
- Identificação de alterações nos arquivos.
- Menu interativo no terminal.

## Tecnologias utilizadas

- Python
- Biblioteca hashlib
- Biblioteca os
- Algoritmo SHA-256

## Objetivo

Projeto prático desenvolvido para aplicar conhecimentos de Python e aprofundar os estudos em Segurança da Informação.
